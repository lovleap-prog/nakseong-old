# 상호작용의 꼴

교과서 탐구 활동을 화면으로 옮길 때 쓰는 꼴들이다. 활동의 성격에 맞는 것을 고르고, 본보기 코드를 읽은 뒤 쓴다. 한 장에 꼴 하나가 기본이고, 둘을 섞을 때는 «실험 1 / 실험 2» 단추로 나눈다.

## 고르는 기준

학생이 그 활동에서 **손으로 하는 일**과 **눈으로 견주는 것**이 무엇인지부터 정한다. 화면은 그 둘만 남기고 나머지를 덜어 낸다.

| 활동의 성격 | 꼴 | 본보기 |
|---|---|---|
| 한 가지를 조금씩 바꾸며 재고 그래프로 그린다 | 막대 → 기록 → 그래프 | `season` `day`, `year` |
| 실제로 재서 표를 채운다 | 측정값 입력 + 계산값과 견주기 | `season` `day`의 «우리 반 측정값» |
| 조건 두 가지를 견준다 | 나란히 놓기 / 바꿔 보기 | `electric` `series`, `season` `orbit` |
| 여러 경우를 예상하고 확인한다 | 예상 → 확인 표 | `electric` `circuit` |
| 물질·물체를 하나씩 넣어 본다 | 넣어 보기 → 결과 표 | `electric` `circuit` 실험 2 |
| 각도·방향에 따라 달라지는 양 | 기울이기 → 막대 그래프 두 개 | `season` `light` |
| 켜고 끌 때 달라지는 것 | 스위치 + 모드 | `electric` `magnet` |
| 쓰임새를 체험한다 | 작은 놀이(목표 3개) | `electric` `crane` |
| 생활 속 실천·안전 | 상황마다 행동 고르기 → 분류 | `electric` `safe` |
| 시간에 따라 벌어지는 일 | «하루 보내기»·«공전시키기» 재생 | `season` `year`, `orbit` |

## 꼴마다의 요령

### 막대 → 기록 → 그래프

- 막대의 범위와 눈금은 교과서의 측정 조건에서 가져온다(오전 9시 30분~오후 3시 30분, 한 시간마다)
- 측정 시점을 지날 때 점이 찍힌다. 빠르게 끌어도 빠지지 않게 «지난 값과 지금 값 사이의 측정 시점을 모두» 기록한다
- 기록이 다 찼을 때 물음을 연다. 물음은 그래프를 읽어야 답할 수 있게 한다(«가장 높은 때는?»)
- 값이 셋이면 색 셋을 정해 읽을값·선·범례·축 숫자에 같은 색을 쓴다

### 측정값 입력

- 실험 관찰의 표와 칸을 똑같이 만든다. 날짜, 조건(막대기 길이) 칸도 넣는다
- 넣는 대로 그래프가 그려지고 축은 값에 맞춰 잡힌다
- 측정 조건으로 계산한 값을 점선으로 겹쳐 견줄 수 있게 한다. 계산할 수 없는 것(기온)은 겹치지 않는다
- 정답을 정해 두고 채점하지 않는다. 실제 측정은 날마다 다르다. 대신 측정값에서 찾은 것(가장 높은 때)을 보여 준다
- `localStorage`에 저장하되 `try/catch`로 감싸고, 그 기기에만 남는다고 `.fine`에 적는다
- «모두 지우기»는 두 번 눌러야 지워지게 한다(`confirm()`은 게시된 쪽에서 동작하지 않는다)

### 나란히 놓기 / 바꿔 보기

- 두 조건을 한 화면에 나란히 놓을 수 있으면 나란히(전지 한 개 | 두 개). 화면이 좁거나 물체가 하나면 단추로 바꾼다(자전축 기울어짐 ↔ 수직)
- 바꿔 보는 경우에는 두 조건의 결과를 **같은 그래프에 다른 색으로** 남겨, 바꾼 뒤에도 앞의 것이 보이게 한다
- 결과 표는 해 본 칸만 채워진다(«아직 안 해 봤어요»)
- 교과서에 없는 조작을 더할 때(전지 방향 바꾸기)는 보고에서 따로 알린다

### 예상 → 확인

- 예상을 먼저 고르게 하고, 확인한 뒤 «예상과 같아요/달라요»를 보여 준다. 틀린 예상을 나무라지 않는다
- 예상하지 않아도 확인은 할 수 있게 둔다(막지 않는다)
- 경우마다의 그림은 교과서 그림을 확대해 읽은 연결을 그대로 옮긴다. 읽기가 확실하지 않으면 보고에 적는다

### 스위치와 전기가 흐르는 모습

- 스위치는 단추로도, 그림을 눌러서도 여닫을 수 있게 한다
- 닫힌 회로에서만 전선을 따라 점이 움직인다. 끊어진 회로에서는 아무것도 흐르지 않는다
- 낱말은 교과서를 따른다(«전기가 흐른다»). 방향을 강조할 필요가 없으면 화살표를 넣지 않는다

### 작은 놀이

- 목표는 셋 이하, 한 판이 1분 안에 끝나게
- 규칙이 곧 배울 내용이어야 한다(전기가 흐를 때만 붙는다 → 스위치를 열어야 내려놓는다)
- 안 되는 경우도 넣는다(철이 아닌 물체는 붙지 않는다). 왜 안 되는지 한 줄로 알려 준다
- «다시 하기» 단추를 둔다
- 놀이 뒤에 그 쓰임새의 까닭을 묻는 물음 하나

### 3D 장면

- 장면은 물체 몇 개와 바닥이면 된다. 꾸밈(집, 나무)은 핵심을 가리면 뺀다
- 핵심 물체를 크게. 측정 도구가 장면의 주인공이면 실제 비례보다 키우고 `.fine`에 적는다
- 처음 보는 방향을 교과서 그림과 맞춘다(동·남·서가 왼쪽부터 보이게)
- 방위·극·이름은 `label()`로 장면 안에 붙인다
- 옆과 위에서 봐야 하는 것이 다르면 모드를 둘로 나누고(세기 / 극) 모드마다 물체를 다시 놓는다
- 실제 크기·거리와 다르면 반드시 밝힌다(«태양과 지구의 크기, 거리는 실제와 다르게 나타냄»)

## 예상·도전·보여 주기 쓰기

모든 체험 장에 붙는 세 장치다. 본보기는 `src/season`과 `src/electric`의 체험 장에 모두 있다.

### 예상해 보기

- 그 장의 실험이 **화면에서 바로 답을 보여 주는** 물음으로 쓴다. 「하루 동안 막대기의 그림자 길이는 어떻게 달라질까요?」(시각 막대를 움직이면 보인다)는 좋고, 「태양은 왜 동쪽에서 뜰까요?」(이 장에서 보이지 않는다)는 안 된다
- 보기에는 학생이 실제로 가질 법한 생각을 넣는다. 교과서 도입 질문, 오개념(«가까워져서 덥다»), 직관(«계속 짧아진다»)에서 가져온다. 일부러 우스운 보기는 넣지 않는다
- 보기는 2~3개, 짧게. 정답이 늘 같은 자리에 오지 않게 한다
- 물음은 결과를 묻고 까닭을 묻지 않는다. 까닭은 «알게 된 것»과 물음이 맡는다
- 해 볼 일 첫째는 예상을 확인하는 조작이 되게 한다

| 장 | 물음 | 정답 |
|---|---|---|
| 하루(계절) | 하루 동안 막대기의 그림자 길이는 어떻게 달라질까요? | 짧아졌다가 다시 길어져요 |
| 공전(계절) | 자전축이 똑바로 서 있다면 계절은 어떻게 될까요? | 바뀌지 않아요 |
| 직렬연결(전기) | 전지 두 개를 직렬연결하면 전구의 밝기는? | 더 밝아요 |
| 기중기(전기) | 전자석 기중기로 플라스틱병을 옮길 수 있을까요? | 옮길 수 없어요 |

### 도전

- 해 볼 일을 다 한 학생이 한 번 더 생각해야 이루는 목표. 해 볼 일을 되풀이하지 않는다
- 화면의 숫자나 상태로 판정되어야 한다: 「빛의 세기를 50으로 맞춰 보세요」(→ 30°를 찾아야 한다), 「전지가 두 개인데도 불이 켜지지 않게 만들어 보세요」(→ 방향을 바꿔야 한다), 「스위치를 8번 이하로 눌러 철 물체 3개 옮기기」(→ 헛누름 없이)
- 좋은 도전은 개념을 거꾸로 쓰게 한다. 결과를 주고 조건을 찾게 하기(그림자가 가장 긴 달 찾기, 우리나라가 겨울인 위치 찾기)
- 판정의 허용 범위를 둔다(±10분, ±2°). 터치로 정확한 값을 맞추기는 어렵다
- 놀이 장(점수, 목표 물체)은 «더 적은 횟수로»처럼 효율을 목표로 한다

### 보여 주기

- 3~5단계, 다 합쳐 30초 안팎. 교실에서 선생님이 TV로 보여 주며 말을 보탤 수 있는 속도
- 단계마다 설명 한 문장(40자 안팎), 학생에게 보이는 말투(해요체). 그 단계에서 **무엇이 달라지는지**를 말한다
- 차례는 «처음 상태 → 바꾸기 → 결과 → 견주기 또는 결론». 교과서 실험의 차례를 따른다
- 끝난 화면이 학생이 이어서 조작하기 좋은 상태가 되게 한다(스위치를 열어 두고, 바꾼 방향을 되돌린다)
- 시연이 예상의 답을 그대로 말해 버리므로, 선생님 메모에 «예상을 고른 뒤에 보여 준다»를 적어 둔다(가림막이 이 차례를 지켜 준다)

## 주제별 2D·3D 판단

교육과정 수준의 일반적인 판단이다. 실제 단원 구성과 낱말은 받은 교과서에서 확인한다.

| 주제 | 판단 | 조작 |
|---|---|---|
| 지구의 운동, 낮과 밤 | 3D | 지구를 돌려 우리나라의 낮밤, 우주에서 본 모습과 땅에서 본 모습 |
| 달의 모양 변화 | 3D | 달을 공전시키며 지구에서 본 모양을 나란히 |
| 태양 고도·그림자·계절 | 3D | 시각·달 막대로 태양의 길과 그림자 |
| 지층, 화석, 화산, 지진 | 3D 또는 단면 2D | 땅을 잘라 단면 보기, 지층 쌓기 |
| 우리 몸, 식물의 구조 | 3D 또는 단면 2D | 기관을 눌러 하는 일 보기. 겹쳐 있어 가려지면 3D |
| 자석, 전자석 | 나침반과 매달린 물체를 함께 보면 3D, 아니면 2D | 극, 세기 |
| 전기 회로 | 2D | 연결, 스위치, 전지 수 |
| 빛(그림자, 거울, 렌즈) | 2D | 빛이 나아가는 길을 위나 옆에서 |
| 물체의 운동, 속력 | 2D | 달리기 견주기, 거리-시간 그래프 |
| 용해, 혼합물 분리, 산과 염기 | 2D | 넣어 보기, 분류, 색 변화. 입자 그림은 쓰지 않는다 |
| 물의 상태 변화, 날씨 | 2D | 온도 막대, 순환 그림. 입자 그림은 쓰지 않는다 |
| 연소와 소화 | 2D | 조건 세 가지를 켜고 끄기 |
| 생태계, 생물과 환경 | 2D | 먹이 관계 잇기, 수의 변화 그래프 |
